# Code Quiz: Stat! 🚑

A gamified, single-file study game for **30 anatomy & physiology terms** useful to **EMTs, ECG techs, and phlebotomists**.

**▶ Play it:** https://producer456hub.github.io/code-crew/

## How to play
Jeopardy-style board — 6 categories × 5 values = all 30 terms. Pick a tile, beat the 15-second clock, and answer the call.

- 🔥 **Combos** — consecutive correct answers raise your multiplier (up to ×3).
- ⏱️ **Speed bonus** — faster answers score more.
- ⚡ **Bonus tiles** — two random tiles each board pay **double points**.
- 🏅 **Ranks** — finish to earn a rank from 🚑 Rookie up to 🏆 Code Master, with a review list of any terms you missed.

## Terms covered
Blood & marrow (hematopoiesis, red/yellow marrow, nutrient foramen, osteoporosis) · Calcium & rhythm (hyper/hypocalcemia, calcium homeostasis, calcitriol, thyroxine) · Skull, face, spine, and chest bones (cranial → coccyx, ribs, sternum, thoracic cage).

## Tech
Pure HTML/CSS/JS in one file (`index.html`) — no build, no dependencies. Sound is synthesized via the Web Audio API; effects use a `<canvas>` particle system. Touch-friendly.
